运行时端到端主链路

启用 Supervisor 后，每个策略周期先读取输入和机器人反馈，再选择行为。WAITING_INIT 使用固定趴姿保持动作，其余可运行状态由对应策略生成动作。

01 输入手柄 / CLI速度指令；手柄另提供 RB 起身请求
02 感知机器人状态基座、关节及四足接触反馈
03 决策Supervisor选择行为、过滤 command；异常时结束
04 路由BehaviorPolicies趴姿保持 / Init / stand / locomotion
05 推理48 → Policy → 12构造观测并执行 ONNX
06 过渡ActionBlender切策略时连续混合动作
07 控制PD + 力矩限制q_target → τ，限制 ±30 Nm
08 仿真mujoco.mj_step()200 Hz 更新 PD 与物理；50 Hz 重走输入链路

Supervisor 状态机

默认从趴姿等待 RB。Init 仅覆盖腹部朝地且接近水平的姿态；正常运动状态下的未站立检测优先于行走切换。

趴姿起身

WAITING_INITRB 请求 → INIT四足支撑且连续稳定 →STAND

行走与停止

STAND持续运动指令 → WALK指令低于退出阈值 → STOPPING稳定或超时 → STAND；指令恢复 → WALK

未站立与异常处理

正常状态回到支持的趴姿且有 Init 模型 → WAITING_INIT，重新等待 RB DISABLED不支持的姿态、起身倾角超限或异常状态 → 结束本次仿真
当前起身完成条件：高度 > 0.36 m、倾角 < 0.25 rad、平面速度 < 0.05 m/s、角速度模长 < 0.10 rad/s，四足接触并连续保持 0.50 秒。Init 倾角达到 0.55 rad 时中止。

WAITING_INIT、INIT 和 STAND 的 command 均为零；STOPPING 继续使用行走策略并平滑减速。缺少站立模型时回退到零指令行走策略；未站立且缺少 Init 模型时进入 DISABLED。阈值以 TOML 为准。

平地行走 → 复杂地形行走

行走奖励与策略接口保持不变，主要通过地形、reset、指令分布与“真实通过地形”的课程判据增加能力。

地形无限平面8×8 m 地块；中央 2×2 m 平台；0.5 m 过渡；8 级 ±0.5～±4 cm 波形逐级增加连续起伏
Resetx/y ±0.5 m；根速度各轴可达 ±0.5平台中心 x/y ±0.1 m；根速度为零先稳定出生，再主动进入崎岖区
指令10% 静止、25% 纯旋转、65% 混合vx/vy/wz 独立连续均匀采样集中训练移动中的地形通过能力
奖励速度跟踪、腾空时间、姿态、平滑、接触与能耗完全继承，权重不变将提升归因于课程与地形，而非奖励重写
课程无地形课程崎岖路程 ≥1 m、时间 ≥1 s、线速度误差 ≤0.35、角速度误差 ≤0.5；连续成功 2 次升级只有真正通过地形且保持跟踪才升级
边界近似无限3.4 m 处 time-limit 截断并 bootstrap避免进入相邻难度地块

平地站立 → 复杂地形站立

Rough Stand 针对“倾斜三脚站立也能成功”的漏洞，增加分层 reset、策略切换状态、四足接触和左右对称课程。

Rough Stand 的课程指标包括 level、sampled_level、stable_fraction、four_feet_fraction、symmetry_fraction、symmetry_error 和 max_drift。

从训练到运行

所有命令在项目根目录执行。完整参数与资产准备步骤见 中文 README。

01 环境准备训练依赖与 USD项目基线为 Isaac Lab 2.2.1；扩展安装不会自动安装 Isaac Sim。USD 被 Git 忽略，需复制完整资产或从 URDF 转换。
02 训练平地预训练，Rough 微调先训练或选择稳定的平地 checkpoint，再微调 Rough 行走与站立；用 TensorBoard 查看奖励、地形等级、接触率和对称率。
03 导出play.py 自动导出每个检查点目录下生成 exported/policy.pt 与 policy.onnx。MuJoCo 加载导出模型，不直接加载 model_*.pt。
04 部署更新 TOML 模型路径相对路径以项目根目录解析。日志与模型被 Git 忽略；默认路径不会自动选择新训练的模型。
# Isaac Lab 环境：安装、列出任务、短训练
python -m pip install -e source/BPX_test
python scripts/list_envs.py
python scripts/rsl_rl/train.py --task BPX-Locomotion-v0 --num_envs 64 --max_iterations 2 --headless

# 从平地策略微调复杂地形策略
python scripts/rsl_rl/train.py --task BPX-Locomotion-Rough-v0 --num_envs 512 --headless \
  --resume --checkpoint logs/rsl_rl/bpx_locomotion/<run>/model_<n>.pt
python scripts/rsl_rl/train.py --task BPX-Stand-Rough-v0 --num_envs 512 --headless \
  --resume --checkpoint logs/rsl_rl/bpx_stand/<run>/model_<n>.pt

# 回放并导出；GUI 回放必须显式限制环境数
python scripts/rsl_rl/play.py --task BPX-Stand-Rough-v0 --num_envs 1 \
  --checkpoint logs/rsl_rl/bpx_rough_stand/<run>/model_<n>.pt --real-time

# 独立 MuJoCo 环境（Python 3.11+）：安装与模型检查
python -m pip install -r sim2sim/requirements.txt
python sim2sim/validate_setup.py

# 填好 TOML 中三个 ONNX 模型路径后，连接手柄并按 RB 起身
python sim2sim/run_mujoco.py --list-gamepads
python sim2sim/run_mujoco.py --backend onnx --viewer --gamepad --supervisor --duration 120 --log sim2sim/logs/gamepad.csv
无手柄测试：仅启用 Supervisor 不会自动触发起身。直接测试行走策略时，请复制配置，将 base_position 改为 [0, 0, 0.40]，joint_position 改为默认站姿，再以单策略模式运行。default_joint_position 是策略动作零点，不能改成趴姿。

建议阅读顺序

第一次看工程时，按照“接口 → 单任务 → 部署 → 上层切换”阅读，比逐文件随机浏览更容易建立完整心智模型。

STEP 1先理解公共接口bpx_base_env_cfg.py：关节顺序、观测、动作和控制频率。
STEP 2比较五个独立任务先比较平地行走/站立，再看 Rough 版本如何改变地形、reset、reward 与 curriculum。
STEP 3沿 sim2sim 闭环阅读run_mujoco → runner → robot / policy。
STEP 4最后理解行为切换supervisor → behaviors → transition，并结合 CSV 验证。
